## What it does

`main.py` writes a single pickup line, 200 characters at most, as if a
vending machine were flirting with a passing human, to `/output/entry.txt`.

> Are you exact change? Because every time you walk by, all my lights come
> on, my coil spins for nothing, and I can't make change for anyone else.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No network, no dependencies, no secrets — just the standard library.
